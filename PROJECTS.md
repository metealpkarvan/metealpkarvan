# Project catalogue

Downloadable apps, browser demos and developer tools by Mete Alp Karvan. Each project has source code, documentation and an MIT license. Use the release page for installation instructions and packaged downloads.

[← Profile](https://github.com/metealpkarvan) · [Mac compatibility & verification](COMPATIBILITY.md)

## Native macOS apps

All four ship Universal Intel / Apple Silicon packages for macOS 11+. Touch Bar projects also have playable or usable window controls.

| Project | Purpose | Download |
| --- | --- | --- |
| [Pati Cepte · Touch Bar Pet](https://github.com/metealpkarvan/touch-bar-pet) | A living Touch Bar pet with five scenes, earned decorations, permanent adventures, four games and local save recovery. | [Latest release](https://github.com/metealpkarvan/touch-bar-pet/releases/latest) |
| [Şerit · Touch Bar Post](https://github.com/metealpkarvan/touch-bar-post) | Scrolling announcements, notes and reminders with scenes, a privacy curtain and an optional desktop strip. | [Latest release](https://github.com/metealpkarvan/touch-bar-post/releases/latest) |
| [Mazi Sandığı](https://github.com/metealpkarvan/mazi-sandigi) | A Turkish nostalgia journal with photo memories, family interview prompts, postcards and two street-inspired games. | [Latest release](https://github.com/metealpkarvan/mazi-sandigi/releases/latest) |
| [Touch Bar Arcade](https://github.com/metealpkarvan/touch-bar-arcade) | Three native mini games for the MacBook Pro Touch Bar and a playable desktop preview. | [Latest release](https://github.com/metealpkarvan/touch-bar-arcade/releases/latest) |

## Browser tools

Turkish / English interfaces, local records and portable exports. These tools do not require an account or AI API key. Download instructions distinguish standalone files from apps that need a local static server.

| Project | Purpose | Try / download |
| --- | --- | --- |
| [Patch Atlas](https://github.com/metealpkarvan/patch-atlas) | Diff coordinates, transparent attention cues, per-file checklists and a portable review record. | [Live app](https://metealpkarvan.github.io/patch-atlas/) · [Release](https://github.com/metealpkarvan/patch-atlas/releases/latest) |
| [Later Lane](https://github.com/metealpkarvan/later-lane) | A reading tray of up to three links selected around a time budget, with intentions and takeaways. | [Live app](https://metealpkarvan.github.io/later-lane/) · [Release](https://github.com/metealpkarvan/later-lane/releases/latest) |
| [Reply Harbor](https://github.com/metealpkarvan/reply-harbor) | Small conversation batches, editable drafts and calendar follow-ups within a time and energy budget. | [Live app](https://metealpkarvan.github.io/reply-harbor/) · [Release](https://github.com/metealpkarvan/reply-harbor/releases/latest) |
| [Link Loom](https://github.com/metealpkarvan/link-loom) | Searchable link collections, tracking cleanup and bookmark / Markdown exports. | [Live app](https://metealpkarvan.github.io/link-loom/) · [Release](https://github.com/metealpkarvan/link-loom/releases/latest) |
| [Context Capsule](https://github.com/metealpkarvan/context-capsule) | Portable goals and decisions for AI conversations, with pinned cards and a character budget. | [Live app](https://metealpkarvan.github.io/context-capsule/) · [Release](https://github.com/metealpkarvan/context-capsule/releases/latest) |
| [Veil Paste](https://github.com/metealpkarvan/veil-paste) | Consistent aliases for selected private fields, with local restoration of known values. | [Live app](https://metealpkarvan.github.io/veil-paste/) · [Release](https://github.com/metealpkarvan/veil-paste/releases/latest) |
| [Claim Lantern](https://github.com/metealpkarvan/claim-lantern) | Claims, source excerpts and manual review judgments for checking an answer before sharing it. | [Live app](https://metealpkarvan.github.io/claim-lantern/) · [Release](https://github.com/metealpkarvan/claim-lantern/releases/latest) |
| [Return Ticket](https://github.com/metealpkarvan/return-ticket) | Task checkpoints, one concrete next action and a short focus timer for interrupted work. | [Live app](https://metealpkarvan.github.io/return-ticket/) · [Release](https://github.com/metealpkarvan/return-ticket/releases/latest) |
| [Trial Tally](https://github.com/metealpkarvan/trial-tally) | Trial subscription decision dates, receipt notes, commitment labels and calendar export. | [Live app](https://metealpkarvan.github.io/trial-tally/) · [Release](https://github.com/metealpkarvan/trial-tally/releases/latest) |

The [community research record](https://github.com/metealpkarvan/patch-atlas/blob/main/docs/COMMUNITY-RESEARCH-2026-10-05.md) documents the observations behind Patch Atlas, Later Lane and Reply Harbor. Other research-led tools describe their sources and design hypotheses in their own repositories. These are exploratory observations, not measured adoption or effectiveness results.
