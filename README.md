# Mete Alp Karvan

I build small, useful tools and playful experiments. My current projects explore native Mac apps, simple browser interfaces, and practical developer tools with Swift, JavaScript, and Python.

## How I approach projects

- Start with a concrete everyday problem and keep the first version focused.
- Prefer a small dependency footprint and data that stays under the user's control.
- Test behavior that can lose data or produce misleading results.
- Include clear setup instructions, examples, and automated checks.

The featured projects have MIT licenses, usage guides, and GitHub Actions test workflows. Touch Bar Arcade uses Swift and AppKit; Link Loom uses native browser modules; Ship Notes uses Python's standard library and Git.

For bugs or ideas, open an issue in the relevant repository.
