# Mete Alp Karvan

I build small, useful tools that make everyday work easier. My current projects explore simple browser interfaces and practical developer tools with JavaScript and Python.

## Projects

| Project | What it does | Try it |
| --- | --- | --- |
| [Link Loom](https://github.com/metealpkarvan/link-loom) | Turns scattered links into a private, searchable collection. Cleans tracking parameters and exports bookmarks or Markdown. | [Live app](https://metealpkarvan.github.io/link-loom/) |
| [Ship Notes](https://github.com/metealpkarvan/ship-notes) | Turns real Git commits into readable progress notes. Runs locally and exports Markdown or JSON. | [Generated example](https://github.com/metealpkarvan/ship-notes/blob/main/examples/link-loom.md) |

## How I approach projects

- Start with a concrete everyday problem and keep the first version focused.
- Prefer a small dependency footprint and data that stays under the user's control.
- Test behavior that can lose data or produce misleading results.
- Include clear setup instructions, examples, and automated checks.

Both featured projects have MIT licenses, usage guides, and GitHub Actions test workflows. Link Loom uses native browser modules; Ship Notes uses Python's standard library and Git.

For bugs or ideas, open an issue in the relevant repository.
